# AI disclosure

This is a hobby project. The Rust implementation was written entirely by AI through prompts issued in [OpenCode](https://opencode.ai).

No human-authored Rust code exists in this repository. Every line of Rust — from the `Controller` trait and `uinput` backend through the Rhai script engine and CLI — was generated by an LLM in response to prompt-driven architecture and implementation sessions.

A human reviewed and committed the output.

**What this means for consumers:** the code works against the specific virtual controller interface it targets, but it was not written with conventional software engineering judgment — it does not represent a considered design, and it carries no warranty (see [LICENSE](LICENSE)).
